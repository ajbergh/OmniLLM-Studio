# Documentation archive

Files here are historical context, not active planning authority. See [../MASTER_PLAN.md](../MASTER_PLAN.md) for unfinished work and [../README.md](../README.md) for active references.

- `completed/` contains implementation and validation records whose stated phase work is complete (for example Windows Phase 12, Image Studio remediation, Chat orchestration, UI remediation, and RAG v2 validation).
- `superseded/` contains older aggregate roadmaps, platform snapshots, and review checkpoints replaced by versioned current-state documents or the master plan.
- `internal-plans/` contains early implementation prompts and planning drafts retained for technical rationale. Their code paths and phase assumptions must not be treated as current without verification.

Every archived planning file has an opening status note identifying its replacement where one exists.
